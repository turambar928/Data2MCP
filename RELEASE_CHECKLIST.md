# Public release checklist

- [x] Core package, web demo, configurations, scripts, and paper source copied.
- [x] Virtual environments, dependencies, caches, logs, outputs, and large data excluded.
- [x] Copied configuration and frontend defaults contain no API credentials.
- [x] Machine-specific absolute paths removed from the release tree.
- [x] Offline smoke tests and frontend checks documented.
- [ ] Choose and add an open-source `LICENSE`.
- [ ] Replace the citation placeholder after the paper metadata is public.
- [ ] Revoke credentials that appeared in the original working repository.
- [ ] Run a history-aware secret scanner on the repository that will be pushed.
- [ ] Confirm redistribution rights for every future dataset or third-party asset.
