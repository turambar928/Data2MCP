# Contributing

1. Create a focused branch and keep changes scoped to one concern.
2. Follow the existing Python and React conventions.
3. Run `python -m pytest tests/` for backend changes.
4. Run `npm run lint` and `npm run build` from `demo/` for frontend changes.
5. Do not commit credentials, benchmark data, generated outputs, or logs.

Use Conventional Commits, for example `feat(router): add a data source adapter`
or `fix(demo): validate an empty model endpoint`.
